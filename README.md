# 基于stm32的智能自行车尾灯—— 2022-11-30 



打造一款小巧的，可安装至自行车尾的智能尾灯，采用塑料外壳，通过自行车后载货架进行安装。主要功能 包括刹车感应尾灯功能：在自行车刹车时车位LED灯亮起提醒后面车辆；行车安全检测功能：检测行车过程 是否发生侧翻，若侧翻，蜂鸣器报警求救；防盗功能：未使用NFC卡解锁尾灯则进入防盗模式，检测自行车 是否被移动，如果被移动则蜂鸣器自动报警；自行车状态记录安卓软件功能：设计一安卓软件可与尾灯通过 蓝牙进行连接，接收运动信息，以及设置是否被别人移动，是否可能造成的损伤。 相较市面其他自行车辅助工具如智能尾灯不具备报警和示速功能和码表不具备尾灯功能，本产品是两类市面 产品的结合，且成本低廉，在一百元左右。 



模块分析如下：主控MCU采用STM32103C6，搭载FreeRTOS操作系统方便后续产品功能拓展与升级。其中 刹车尾灯功能包括加速度检测模块和LED灯组模块；行车安全检测功能包括陀螺仪角度检测模块，蜂鸣器模 块；防盗功能包括震动检测模块，GPS定位模块，和蜂鸣器报警模块；自行车状态记录安卓软件功能：包括 安卓程序设计，蓝牙通信模块，GPS模块。 



在大学校园这样一个道路环境复杂的环境里，行车安全需要重视起来。而校园里的大学生一般采用自行车出 行，在高峰时期道路拥挤，驾车人面对玩手机过马路的大学生需要灵活机动，后面的车辆却难以及时反映， 很容易发生追尾事故；另外校园里人员混杂，自行车的停放也比较随意，对自行车防盗提出了挑战。因此急 需一款价格大学生能接受的，并且有助于提高行车安全性，自行车防盗性的一款自行车辅助工具，于是开展 智能自行车尾灯项目，将行车安全与防盗功能集成在尾灯之中，兼具美观与便携，小巧与荫蔽，与自行车融 为一体，达成和谐，来提升校园内的行车体验。
