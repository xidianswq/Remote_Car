基于stm32的多功能巡线避障小车
一.文件包括stm32部分源码，包含各个模块的使用；小车主控版PCB设计原理图
①stm32部分：直流电机控制模块、pca9685舵机驱动器模块、mpu6050三轴角度驱动模块、ADC测电压模块、oled屏驱动模块、超声波测距模块、红外传感器模块、摇杆控制模块、舵机控制模块、蓝牙通信模块、蜂鸣器模块、led灯模块、stm32和jetson nano通信的uart模块、定时器模块、pwm波模块
②PCB设计：简单使用两个稳压模块，电源使用12V直流电源，得到5V和3.3V电压
2.代码优点：注释详尽，标注所有资源的使用情况以及管脚的连接情况，易于复现。函数编写规范，模仿HAL库风格，易于理解！
二.使用说明
1.要结合作者的文章——图像识别小车——电赛学习笔记，四部分，来学习应用，防止程序无法正确运行
注：由于小车使用模块较多，资源使用紧凑，要修改引脚分配难度大，会造成很多影响，不建议随意修改
